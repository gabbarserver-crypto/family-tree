# FamilyTree V11 — Support System

## Support features
- Support tickets
- Ticket ID
- Categories
- Priority
- Open/In Progress/Resolved/Closed
- User ↔ Support chat
- Attachments foundation
- Multiple support staff
- Ticket assignment
- Notifications
- Audit history
- Reopen/resolution workflow

## Privacy
Support staff are not family members and do not automatically receive access to a user's family tree.

Support access should be limited to the information necessary to resolve the ticket.

## Categories
- Login / OTP
- Family Tree
- Profile Claim
- Duplicate / Merge
- Reels / Media
- Family Wall
- Account
- Other

## Roles
- Support Staff: handle assigned tickets
- Admin: manage tickets/staff and escalations
- Super Admin: global support configuration

## Recommended Supabase Storage
Private bucket:
- support-attachments

Use signed URLs and Storage RLS.
